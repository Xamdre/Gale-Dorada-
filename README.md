# GALE DORADA
Tienda en línea desarrollada con Next.js y TypeScript.

## Desarrollo
1. Instala Node.js 20 o superior.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev`.

## Próximas integraciones
Supabase para productos, inventario y pedidos; Wompi para pagos; Google Calendar para agenda.
No se deben publicar claves privadas en el navegador ni en el repositorio.
